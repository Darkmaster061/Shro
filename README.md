# پرتال هوشمند نوورودی‌ها — مجتمع آموزش عالی گناباد

پرتال جامع استقبال از نوورودی‌ها ویژه بسیج دانشجویی و هیئت دانشجویی، شامل راهنمای ثبت‌نام، خوابگاه‌ها، معرفی کانون‌ها و نمایشگر PDF، سامانه ژتون صبحانه (QR) و اسکنر آفلاین مسئول پخش.

## اجرای محلی

```bash
npm install
npm run dev
```
سپس نشانی `http://localhost:3000` را باز کنید.

## مسیرهای مهم سامانه

- `/` — صفحه اصلی پرتال و خوش‌آمد اولیه (Gate)
- `/guide` — چک‌لیست ثبت‌نام، مدارک، نقشه تعاملی دانشگاه، سوالات متداول با جستجوی فازی فارسی و فرم «سوالت را بپرس»
- `/dorms` — خوابگاه‌ها، مقایسه کنار هم و چک‌لیست قابل چاپ وسایل خوابگاه
- `/basij` — معرفی بسیج دانشجویی، کانون‌ها، نمایشگر PDF دفترچه و آزمون «کدام کانون به من می‌خورد؟»
- `/heyat` — برنامه‌های هیئت و دریافت کارت دیجیتال ژتون صبحانه
- `/scanner` — اپلیکیشن اسکنر مسئول پخش صبحانه (قابل استفاده در حالت آفلاین)
- `/admin` — پنل مدیریت محتوا، لوگوها، لیست دانشجویان و گزارش‌ها

## کارهای ضروری پیش از انتشار رسمی

1. تغییر رمز عبور حساب‌های پیش‌فرض با دستور `npm run create-admin`.
2. ورود به `/admin` و کلیک روی دکمه **«حذف یکجای تمام داده‌های نمونه»**.
3. آپلود **لوگوی بسیج**، **لوگوی هیئت** و **فایل PDF دفترچه کانون‌ها** (تا ۵۰ مگابایت) در تب «تنظیمات و لوگوها».
4. تکمیل لینک‌های واقعی تلگرام/ایتا/بله، شماره‌های تماس، اطلاعات خوابگاه‌ها و تاریخ ثبت‌نام در محل‌هایی که با `[نیاز به تکمیل]` مشخص شده‌اند.
5. ورود لیست واقعی نوورودی‌ها از طریق فایل CSV (ستون‌ها: `نام,نام‌خانوادگی,تاریخ تولد,توضیحات` با فرمت شمسی مثل `۱۳۸۷/۰۵/۲۰`).
6. آموزش کوتاه مسئول پخش صبحانه برای ورود به `/scanner` و فعال‌سازی دوربین (در محیط واقعی روی HTTPS).
